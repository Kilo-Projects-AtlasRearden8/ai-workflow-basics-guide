# Choosing AI Tools — A Beginner's Guide

**Asdale Dynamics, LLC** — beginner-friendly AI education, books, and tools.
Plain English, step by step. Local first. No API keys required.

---

## Why this chapter exists

There are a lot of AI tools out there, and more show up every week. It is easy
to feel like you are already behind. You are not. Most people only need one or
two tools to get started, and the best tool is the one you will actually use.

This chapter walks you through choosing your first AI tools without spending
money you do not need to spend and without handing over private data.

---

## Step 1: Decide what you want to do

Before you look at any tool, write down one real task you want help with.
Examples:

- Writing a book blurb or newsletter
- Summarizing meeting notes
- Turning a rough idea into a blog post
- Organizing paperwork or a simple budget
- Writing a bit of code for a personal project

Pick **one** task. You do not need a strategy. You need a starting point.

---

## Step 2: Know the main kinds of AI tools

| Kind | What it does | Good for beginners? |
|------|--------------|---------------------|
| AI chatbot | You type, it answers | Yes — best place to start |
| Local LLM | An AI model that runs on your own computer | Yes, if you want privacy |
| AI coding assistant | Helps write and fix code | Yes, if you are building something |
| Automation tool | Moves data between apps | Later, once you know the basics |
| Agent / MCP tool | Chains several AI steps together | Later — see Chapter 2 |

Start with an AI chatbot. Everything else builds on that habit.

---

## Step 3: Choose between cloud tools and local tools

### Cloud tools (websites and apps)

Examples: the free tier of a mainstream AI assistant, browser-based chat tools.

**Pros:** No setup, works on any device, often free to start.  
**Cons:** Your text goes to someone else's server, you need an internet
connection, free tiers usually have limits.

### Local tools (run on your computer)

Examples: a local LLM runner such as Ollama or LM Studio, running a small model
on your laptop.

**Pros:** Your data stays on your machine, works offline, no account needed,
no usage limits.  
**Cons:** You need to install software first, your computer needs to be
reasonably modern, models take up disk space.

**Beginner recommendation:** Start with a free cloud chatbot to learn how to
talk to AI. When you want privacy or offline access, try a local tool next.

---

## Step 4: Check these five things before you commit

Ask about any tool you are considering:

1. **Cost:** Is there a free tier? What happens when you run out of free uses?
2. **Privacy:** Can you read the privacy policy in plain language? Does your
   input train someone else's model?
3. **Ease of use:** Can you start within ten minutes of installing?
4. **Portability:** Can you copy your conversations out? (Look for export or
   copy/paste.)
5. **Offline:** Does it work without internet? (Only local tools do.)

If a tool fails more than two of these, keep looking.

---

## Step 5: Suggested starter stack (all free or have free tiers)

| Goal | Tool type | Example options |
|------|-----------|-----------------|
| General chat and writing | Cloud chatbot | Any mainstream free AI assistant |
| Private, offline writing | Local LLM | Ollama or LM Studio with a small model |
| Coding help | AI coding assistant | Free tier of a mainstream coding AI, or a local code model |
| Organizing notes | Local notes app with AI plugin | Any app you already use — add AI later |

You do not need all of these. Pick one row and try it for a week.

---

## Step 6: Your first session (10 minutes)

1. Open your chosen tool.
2. Type this: *"I am new to AI. I want help with [your one task from Step 1]. Ask me three questions so you can give me a good first draft."*
3. Answer the questions.
4. Read the result. Change anything you do not like.
5. Save what you liked somewhere you can find it again.

That is it. You have used an AI tool.

---

## A quick word on cost

Free tiers change often. This guide does not list prices because they will be
wrong by the time you read this. Check the tool's pricing page before you
enter payment details. You can do almost everything in this guide with free
tools.
