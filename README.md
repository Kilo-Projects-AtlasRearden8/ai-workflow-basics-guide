# AI Workflow Basics Guide

A beginner-friendly manual on simple AI workflows: choosing tools, chaining
prompts, and keeping humans in the loop. Plain English, step by step, local
first, no API keys required.

Brought to you by **Asdale Dynamics, LLC** — Indiana, formed October 2026.
Beginner-friendly AI education, books, and practical tools. This guide is a
companion to *The Massive AI Manual* by Dylan Asdale and the hub site
dylanasdale.github.io.

## What's inside

- `docs/` — the beginner manual in Markdown (printable and easy to copy)
  - `01-choosing-tools.md` — how to pick AI tools as a beginner
  - `02-chaining-prompts.md` — linking prompts together step by step
  - `03-humans-in-the-loop.md` — review checkpoints and human judgment
  - `printable-planner.md` — one-page workflow planner worksheet
- `site/` — static HTML version of the manual, ready to open in any browser
  - `index.html` — home and overview
  - `choosing-tools.html`, `chaining-prompts.html`, `humans-in-the-loop.html`
  - `planner.html` — print-ready planner worksheet
  - `tools/prompt-chain.html` — local-first prompt chaining sandbox (no keys)
  - `style.css`, `script.js` — site styles and interactivity

## Who this is for

Anyone new to AI who wants to use it practically without getting overwhelmed.
Written especially for small-business owners, authors, healthcare workers
(education only — never medical advice), and anyone who wants to keep control
of their own tools and data.

## Local first, no keys

Everything in this guide works without creating accounts, buying subscriptions,
or pasting API keys into files. The `site/tools/prompt-chain.html` sandbox runs
entirely in your browser and stores nothing on a server.

## How to use

1. Read the manual in `docs/` (Markdown) or open `site/index.html` in your
   browser.
2. Follow each chapter step by step and try the examples with a tool you
   already have.
3. Print `site/planner.html` (press Ctrl+P / Cmd+P) and fill it in by hand for
   your first real workflow.
